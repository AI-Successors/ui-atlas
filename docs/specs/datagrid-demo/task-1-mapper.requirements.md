## Approved live discovery and inspection increment

The approved visual concept replaces the noisy green overlay with source-specific outlines and a small Recording-style grid inspector. The original increment added discovery and information only. The user subsequently authorized the [Task 3 Explore / Stop flow](task-3-extraction.requirements.md), which now occupies the same inspector. It does not qualify a business-data reader or change application records.

- **T1.8:** Ordinary UI Automation controls use thin blue (`#0A84FF`) outlines. Computer-vision controls use violet (`#8B5CF6`) corner brackets. Native grids use a solid teal (`#008F83`) whole-grid boundary. Potential non-native grids use a dashed amber (`#C98208`) whole-grid boundary. Labels and line styles distinguish types without relying on color alone. No full-window color wash or per-cell/text-fragment rectangles inside grids.
- **T1.9:** Native classification requires current UIA Grid/Table pattern evidence from a native provider. Visual observations advertising a synthetic Grid pattern remain candidates. Grid-like native hosts without proven patterns also remain explicitly unverified candidates; their source is named truthfully. Equivalent native/visual detections resolve to one boundary; separate grids remain independently selectable.
- **T1.10:** Clicking a displayed grid or its label opens one compact, floating, draggable, closeable inspector. The current Table Explorer shows the name and native/candidate classification, then the Task 3 Explore / Stop and image-result actions. Detection source and native-support evidence remain part of the classification model; the original information-only card is superseded. Native structure is not a reading or completeness claim. Selecting another grid updates the same inspector. There are no application-data edit actions.
- **T1.11:** Grid inspection clicks are consumed by Mapper and do not select/edit a business cell, initiate recorder actions, or request scrolling. Scrolling requires the separate explicit Explore action. Non-grid controls retain normal interaction. Overlays hide for screenshot capture and restore when all capture scopes finish. During ordinary automatic input/scanning, keep the visuals present while disabling their input interception. Image exploration deliberately holds mapper and recorder decorations hidden for its capture interval while keeping Stop outside the table; restore them when the exploration scope ends. Disposal closes every owned overlay/inspector window.
- **T1.12:** Overlays follow the active recording session, not keyboard focus. Clicking elsewhere must not erase or hide the map on still-visible portions of the target, or hide the legend. Covering windows clip the corresponding drawing and hit regions so Mapper cannot draw or intercept clicks over another app. Moving the target repositions bounds; resizing or changing surface triggers passive refresh without needing another recorded click. Hidden/minimized/closed targets have no grid hit regions. Empty completed scans clear old grids while refresh remains active; unavailable/screenshot-only observations do not mean controls disappeared. Overlay coordinates honor physical pixels, DPI, and negative monitor origins.
- **T1.13:** The legend is a separate draggable floating panel, initially placed outside the target's boundaries in available desktop work area. Hide collapses it to a small movable restore button; clicking that button restores the legend. Position and collapsed state survive refreshes and temporary capture hiding within a mapping session. Restore keeps the panel reachable on-screen. If there is room only for the small button, start collapsed; if the target fills all available desktop space, retain a reachable edge button without moving/resizing the target.
- **T1.14:** Do not discard current UIA evidence just because a legacy provider calls a control `Pane`, `Custom`, or `Group`. Named leaf controls outside grids retain blue outlines. Suppress surrounding structural containers, hidden controls, cached-only evidence, and grid cell noise. This presentation policy does not alter collected or saved UIA data.

Acceptance: test native and visual grids (including synthetic Grid patterns), opaque host candidates, overlapping detections, multiple grids, cell suppression, empty refresh, click isolation, inspector selection/close, capture exclusion, target movement/resize/foreground loss and teardown. Render and inspect both card states and run a real window smoke using synthetic business data. Report actual live-app validation separately.

## Required outcomes

- **T1.1 (R2-R4):** Identify an Abacre grid candidate separately from individual controls/cells. Allow explicit selection when discovery is ambiguous. Show whether a reading mechanism has actually been verified.
- **T1.2 (R3-R4):** Bind the selection to an existing map, owning surface, and live host ancestry. Saved coordinates alone are insufficient. A saved mapping must be reloadable without retaining old process handles as durable identity.
- **T1.3 (R4):** Save ordered column identities and labels, schema completeness, supported axes, and structural information sufficient for reacquisition. Incomplete horizontal discovery must not become a claimed total column count.
- **T1.4 (R5):** Provide one small diagnostic panel/dialog: table selection, header/body preview, ordered columns, qualification, current stage, counts, coverage, restoration, and actionable failure reason. Default visualization is the table and header/body boundaries; no cell-outline dashboard.
- **T1.5 (R6-R7):** Let the user initiate approved bounded acquisition while mapping, observe progress, and cancel. Use the same capture/extraction behavior as MCP. A mapping run must not start while an incompatible recording operation is active.
- **T1.6 (R10-R11):** Display capture, extraction, and restoration separately. A partial attempt must not overwrite an existing qualified schema with guessed structure.
- **T1.7 (R13):** Existing maps without grid definitions remain readable. Saving, reopening, and local catalog listing preserve the grid definition. Ordinary recorder/map workflows still work.
