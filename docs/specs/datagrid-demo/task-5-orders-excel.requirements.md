## Outcome

The request “Extract orders from Abacre Hotel Management Software and save them to an Excel file in Downloads” discovers the running app, identifies Orders in its current UI, obtains local HUD approval, reads the reachable table using the saved Azure OpenAI configuration, and saves a verified `.xlsx` file. The user does not supply map IDs, tool names, scroll directions, credentials, or an Excel window.

## Requirements

- **R1 Discovery:** `list_apps` is the first application tool. Match the requested app against product name, process and window title. Separate live window instances. `list_app_grids(appId)` binds saved grids to that exact current window without capture, scrolling or a HUD. Return live availability, saved columns, schema completeness and a specific readiness reason. No map or hidden Orders screen is an explicit result, never a request for arbitrary UI automation.
- **R2 Read:** `start_grid_read(appId, gridRef, requestId)` returns promptly and opens the existing HUD for the selected table. Approval names full reachable rows/columns, Azure table-image transcription and capture limits. No capture, cloud submission or scroll occurs before approval. Rebind process instance, owner, host and geometry after approval. Preserve Stop, takeover, operation exclusion and safe restoration.
- **R3 Scope:** traverse both axes using the existing bounded image engine. Full means currently reachable rows and columns under existing UI filters; no hidden columns, other pages or database completeness is implied. Retain independent capture, extraction, column coverage, row coverage and restoration outcomes. Limits or uncertain joins must not become complete output.
- **R4 Azure:** reuse the table explorer's saved endpoint/deployment and Credential Manager key without duplicating secrets. Add literal cell transcription with fixed physical row/column identities, exact response cardinality, blank/unreadable distinction, no invented values and retained evidence. Images are untrusted data. Bound requests and response sizes and propagate cancellation. Authentication, timeout and malformed output have explicit reasons. No silent local OCR fallback.
- **R5 Schema:** the saved Orders header is currently incomplete. Fresh full-width evidence must establish physical columns and row regions before reading. Saved labels are hints, not authority to discard additional columns. Do not change a persisted map or set local OCR qualification flags to bypass the earlier failed qualification.
- **R6 Results:** poll the same acquisition until terminal; expose bounded row pages and an immutable dataset ID. Duplicate request IDs return the same operation; conflicting reuse fails. Unknown/expired IDs never restart capture. Retain datasets with the existing bounded operation lifetime. Reading success is validated on fresh Abacre evidence, separately from synthetic tests.
- **R7 Excel:** `export_grid_to_excel(datasetId)` writes directly to the user's Windows Known Folder Downloads without opening Excel. Preserve literal identifiers and Unicode, escape formula-like source text, retain duplicate headers by physical position, show unreadable cells explicitly, and never overwrite an existing file. Include acquisition scope/status and source timestamp. Reopen and verify all cells and row/column counts before returning the absolute path and SHA-256. Partial data needs explicit `allowPartial=true` and an unmistakably partial workbook; failed/no-data reads cannot export as Orders.
- **R8 Routing:** deliver a discoverable `ui-atlas-grid-export` skill. It requires the public MCP discovery/read/export tools, prohibits Computer Use and UI automation fallbacks, selects Orders automatically when unambiguous, waits for local human approval, and reports exact blockers. Instructions are not a host-level tool allowlist; the acceptance transcript must show no Computer Use calls.
- **R9 Boundaries:** implement in this public repository using its existing public components. Preserve unrelated work. Do not change application records, sort/filter the table, alter credentials, or silently change provider settings. Application data and live evidence stay outside tracked source.
