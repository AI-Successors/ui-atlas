# UI Knowledge Graph v2

`ui-atlas.uikg/2` makes observed grounding layers explicit. The SQLite file remains the authoritative local build artifact. The default `export map <id>` produces the human-readable `ui-atlas.map.json/1` projection: Raw Data Streams, Raw World, and Semantic World each contain windows; windows contain variants; variants contain their observed controls. Explicit source ID arrays preserve window, variant, and control lineage across worlds. The lower-level `ui-atlas.uikg.export/1` graph interchange remains available through `map export json`; its order indexes preserve the canonical node and edge sequence for exact graph round trips.

The shared layer contains the selected application. Raw Data Streams contains one native window surface and its raw UIA controls for each captured observation package, preserving the provider-reported owner. Raw World fuses those observations into durable surfaces and controls and adds per-surface state variants, hierarchy, containment, and observed transitions. When a scoped owned window is bounds-matched to a UIA runtime subtree reported through its root provider, Raw World assigns that subtree to the effective owned surface without rewriting Raw Data Streams. Every Raw World surface carries one or more `sourceRawDataStreamSurfaceId` lineage properties. Semantic World contains generalized windows, popup families and variants, and coalesced controls and inherits the effective raw owner. Every Semantic World surface or control carries one or more `sourceRawSurfaceId` or `sourceRawControlId` lineage properties. Validation rejects missing or incompatible world structure.

Raw surface classes are `RawWindow`, `RawDialogWindow`, `RawToolWindow`, and `RawPopupWindow`. Classification uses native ownership, class/style facts, and relative geometry; borderless or transient popup evidence takes precedence over the generic tool-window style bit. Owned-surface identity includes a stable owner-surface token, and popup identity includes observed control/layout shape. Literal titles are not identity inputs. Semantic surfaces retain their structural `Window`, `PopupFamily`, or `PopupVariant` role and publish a display class of `SemanticWindow`, `SemanticDialogWindow`, `SemanticToolWindow`, or `SemanticPopupWindow`. Control identity prefers stable accessibility IDs and otherwise uses control type, class, hierarchy, and normalized relative geometry. Runtime IDs establish hierarchy only within a frame. HWND, PID, timestamps, literal labels, and absolute paths never participate in canonical IDs.

Raw state variants are hashes of visible control membership and enabled state. The explorer filmstrip is observation based: each card identifies one retained representative frame and the controls evidenced in that frame, while repeated state hashes remain available as derived graph state. Raw Data Streams remain lossless. Raw World and Semantic World default filmstrips hide empty frames, frames whose effective content belongs to an owned popup, exact duplicates, and only very-high-similarity visual duplicates; each hidden observation retains a deterministic reason and survivor identifier in the read model. Reordered provider results and DPI-scaled geometry do not change durable control identity. Semantic controls are coalesced across observed variants by their durable Raw World endpoint. This gives consumers a reusable surface/control catalog while retaining traceable state evidence.

Full-evidence graphs retain sensitive labels, native observations, source-bundle linkage, frame bounds, and optional screenshot evidence. `safe/1` exports generate a fresh unlinkable ID namespace, remove all labels/properties, clear timestamps, source linkage, native coordinates, and screenshot references, and preserve only generic node kinds and topology. A safe export cannot be converted into the identity-bearing compatibility format.

V1 JSON and SQLite graphs are accepted through an explicit read migration into a `legacy-observed` layer. Migration does not claim Raw or Semantic World understanding that was absent from the source. New publications are always v2.

The graph contract schema is [uikg-v2.schema.json](../schemas/uikg-v2.schema.json), the human map schema is [map-json-v1.schema.json](../schemas/map-json-v1.schema.json), and the lower-level graph interchange envelope is [uikg-export-v1.schema.json](../schemas/uikg-export-v1.schema.json). Legacy flat v2 graph JSON remains readable. A new required world concept, identity algorithm, or lossy field change requires a new major identifier.
