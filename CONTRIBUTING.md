# Contributing

Use the pinned SDK and locked restore described in the README. Keep changes inside this repository, add focused tests, and run Release build plus all tests.

Contributions must be original or come from a source with redistribution terms compatible with this repository. Record every new file and external source in `provenance/files.csv`; update third-party notices, lock files, and the SBOM for dependency changes. Do not submit real recordings or machine-local artifacts.

By contributing, you certify that you have the right to submit the work under the repository license and agree to the Developer Certificate of Origin 1.1. Add `Signed-off-by: Name <email>` to each commit.
